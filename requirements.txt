# Runtime. The upper bound is deliberate: reading the capture driver's
# dropped-packet counters reaches through private scapy internals
# (sock.pcap_fd.pcap) that carry no stability guarantee. It degrades to "drops
# unknown" rather than crashing if that chain changes, but the pin keeps an
# upgrade a decision rather than a surprise.
scapy>=2.7.0,<2.8
#
# A pcap backend is a prerequisite, not a pip dependency:
#   - Windows: Npcap, installed separately from npcap.com.
#   - macOS:   the system libpcap at /usr/lib/libpcap.dylib, which ships with
#              the base OS.
#
# Development / test only:
pytest
